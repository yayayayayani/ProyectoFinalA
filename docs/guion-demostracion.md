# Recorrido de demostración (8–10 minutos)

1. **Inicio:** explica que las cifras se consultan en MySQL, no son números decorativos.
2. **Equipos:** crea un equipo, abre su plantilla y muestra la lista de equipos.
3. **Jugadores:** inscribe a un jugador con nombres, apellidos, fecha, equipo y fotografía.
   Muestra la búsqueda y la ficha. Edita sin subir una foto y comprueba que se conserva.
4. **Jornadas:** crea una jornada con su fecha antes de registrar resultados.
5. **Goles:** registra un total para un jugador/jornada. Intenta repetirlo para mostrar
   la validación, luego modifica el registro existente.
6. **Incidencias:** registra una tarjeta amarilla. Luego registra una roja indicando
   la fecha de suspensión. Intenta omitirla para mostrar el mensaje de error.
7. **Árbitro:** consulta la Jornada 2 · Demo (17/10/2026): Valentina Castillo aparece
   suspendida. En la Jornada 3 vuelve a estar habilitada según la regla de fecha exacta.
8. **Incidencias:** filtra por Halcones FC · Demo y luego por Valentina Castillo.
9. **Goleadores:** muestra el orden descendente, fotografías y equipos; pulsa
   Imprimir / guardar PDF y selecciona Guardar como PDF en el navegador.
10. **Código:** explica una entidad, un formulario, un controlador y la consulta
    `SUM(g.cantidad)` de `EstadisticasTorneo`. Explica CSRF, consultas parametrizadas,
    validación del servidor y nombres aleatorios para las fotografías.

No uses datos personales reales para una demostración pública. Los registros
marcados Demo y sus avatares fueron creados específicamente para presentar el sistema.
